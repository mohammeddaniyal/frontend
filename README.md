# Frontend Learning Repository

This repository is a structured learning space for practicing HTML and CSS concepts from the frontend course. It contains lesson notes, reference material, demo exercises, and project work used during daily practice.

The goal is simple: read the lesson, try the example, modify the code, and understand why the result changes.

## Repository overview

- `notes/` — daily lesson notes and explanations
- `topics/` — HTML/CSS practice files and demos for each topic/day
- `project/` — progressive profile project work across multiple days

## How to use this repository

For each lesson:

1. Read the notes for that day.
2. Open the matching example from `topics/`.
3. Change the HTML or CSS and refresh the page to see the result.
4. Try rebuilding the example without looking at the reference first.

> The goal is not to copy code blindly. The goal is to understand the behavior and then recreate it with your own changes.

## Recommended workflow

- Start with the daily notes.
- Practice the pattern in the matching topic file.
- Make small changes to test what each property does.
- Rebuild layouts without copy-pasting.
- Review older days whenever a new concept depends on a previous one.

## Learning goal

The aim is to build a solid understanding of:

- HTML structure
- CSS styling and layout
- responsive design
- visual interaction patterns
- reusable styling with CSS variables

This repository is a practice archive and study companion for building frontend fundamentals.
