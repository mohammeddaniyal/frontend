# Day 2 — HTML

## 1. Links

The `<a>` element creates a hyperlink to another page or resource.

Example:

<a href="contact.html">Contact Me</a>

`href` specifies the destination of the link.

---

## 2. Relative URLs

A relative URL specifies a resource location relative to the current page.

Example:

<a href="contact.html">Contact</a>

If both files are in the same folder, only the filename is needed.

---

## 3. Images

The `<img>` element displays an image.

Example:

<img src="images/profile.jpg" alt="Mohammed Daniyal">

`src` specifies the image location.

`alt` provides alternative text describing the image.

---

## 4. Unordered Lists

The `<ul>` element creates an unordered list.

`<li>` represents an item in the list.

Example:

<ul>
    <li>C</li>
    <li>C++</li>
    <li>Java</li>
</ul>

---

## 5. Ordered Lists

The `<ol>` element creates an ordered list.

`<li>` represents an item in the list.

Example:

<ol>
    <li>Learn HTML</li>
    <li>Learn CSS</li>
    <li>Learn JavaScript</li>
</ol>

---

## Remember

<a>  → link
href → destination

<img> → image
src   → image location
alt   → alternative text

<ul> → unordered list
<ol> → ordered list
<li> → list item
